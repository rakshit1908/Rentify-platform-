ERROR 1: "Port 5173 is already in use"
─────────────────────────────────────────
Pehle wala server band karo:

netstat -ano | findstr "5173"
taskkill /PID <process_id> /F

Phir se npm run dev karo.


ERROR 2: "node is not recognized"
─────────────────────────────────────────
Node.js install nahi hai.

Download: https://nodejs.org/
Install karo, phir terminal restart karo.


ERROR 3: "Cannot find module"
─────────────────────────────────────────
Dependencies install nahi hui:

cd d:\Rentify\frontend
npm install

cd d:\Rentify\backend
npm install


ERROR 4: White/Blank page in browser
─────────────────────────────────────────
Hard refresh karo:

Ctrl + Shift + R

Ya cache clear:

Ctrl + Shift + Delete
